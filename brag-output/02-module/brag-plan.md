# Brag Plan: MediaForge — Folge 2/5: Module & Theme-Pakete

> Final copy: English (changed mid-run at the user's request). The rendered video and composition-brief.md hold the English text; German lines below are the original draft.

## What is this app?
MediaForge (free, self-hosted media downloader + library) can be extended with store-installable modules and reskinned with CSS-only theme packs from the same store, managed in one page: the Modulmanager with three views (Installiert / Store / Einstellungen).

## The angle
"Deine App. Deine Regeln." The store is real: 11 modules and 28 theme packs live in the official index today (mediaforge.pd-codes.net/store). Show browsing it, installing a real module, and a theme pack changing the whole UI live.

## Hook (0–2.4s)
The MediaForge UI frame flips through three real theme looks in quick succession (default violet → Star Trek LCARS amber → Matrix Terminal green), then the line "Deine App. Deine Regeln." lands.

## Key moments
- Modulmanager tabs "Installiert · Store · Einstellungen"; Store split browser: facet list left (Alle, Module, Themes), rows of real entries: AniFilter, Anime Seasons, Discord Request Bot, Jellyfin Connector, Resolution Badge, Planned Releases — each with a type badge and "Offiziell"/"Verifiziert".
- Detail pane of "Resolution Badge" ("Zeigt die Auflösung jeder Episode im Download-Fenster an, noch vor dem Download.") → cursor clicks "Jetzt installieren" → state "Installiert".
- Theme packs: a grid of theme swatches (Dracula, Nord, Cyberpunk 2077, Gameboy Classic, Sakura Theme, Catppuccin Macchiato); one click and the mock UI recolours live.
- "Bau dein eigenes Modul" — module kinds from `.examples/thirdparties`: Content-Quelle, Untertitel-Quelle, CineInfo-Quelle, Neuer Tab, Dashboard-Widget, Hooks.

## Outro / punchline
"11 Module. 28 Themes. Und deins?" → logo, `mediaforge.pd-codes.net`.

## User flow worth showing
Open Store → pick module → Jetzt installieren → installed; pick theme → UI recolours.

## Tone
- Preset: app-store
- Creative direction: clean feature-card store tour, smooth slides, calm confidence
- Interpretation: slides and morphs, fewer hard cuts, each card readable.

## Format: vertical — 1080x1920
## Duration: 22s

## Visual identity
Same MediaForge tokens: #0d0d14 / #16162a / accent #7c3aed / #2563eb / text #f0f0f8 / #9191b0, Inter. Theme looks from the store names (LCARS amber #ff9900 / ice blue #99ccff; Matrix #00ff66 on #000).

## Storyboard
